The "unreadable" lines emitted by the same probe for GSE39582/GSE104645/
GSE28702/GSE72970/GSE69657 are an artefact: the probe built its library path
with escaped Unicode that this locale could not resolve, so no library
directory was searched at all. The per-cohort verdicts below come from a second,
path-safe run and are the ones to rely on.

Why this matters: the manuscript's DEG layer was produced with limma, yet limma
was not installed in any R library on the analysis machine at deposit time. The
Bioconductor binaries used to reproduce it (limma 3.68.5, edgeR 4.10.5, Biobase
2.72.0) were installed afterwards into a project-local library via
../install_deps.R, so a fresh clone must do the same before the DEG scripts will
run.
